# BlueBoy build and runtime dependencies
#
# BlueBoy is a C++17 project that links against BlueZ (libbluetooth).
# There are no Python, Rust or Node dependencies.

# Build toolchain
cmake >= 3.16
g++ (or clang++) with C++17 support
make (or ninja)

# Runtime / link dependency
bluez                      # BlueZ stack, provides libbluetooth
libbluetooth (headers)     # bluetooth/bluetooth.h, hci.h, sdp.h

# Optional, for manual verification of findings
bluez-utils                # bluetoothctl, hciconfig

# Arch:
#   sudo pacman -S base-devel cmake bluez bluez-libs bluez-utils
# Debian/Ubuntu:
#   sudo apt install build-essential cmake libbluetooth-dev bluez bluez-tools
# Fedora:
#   sudo dnf install gcc-c++ cmake bluez-libs-devel bluez
